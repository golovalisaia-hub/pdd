# PDD

Веб-приложение для подготовки к теории вождения категории ABM. В PDD есть два авторских учебных билета, экзамен с дополнительными блоками, 36 интерактивных перекрёстков, избранное, повторение ошибок, десятиминутная тренировка, прогресс и справочник. История хранится в браузере.

## Открыть приложение

[PDD на GitHub Pages](https://golovalisaia-hub.github.io/pdd/)

На iPhone открой эту ссылку в Safari и выбери «Поделиться → На экран “Домой”». Для работы без сети открой приложение по ссылке и дождись сообщения «Кэш готов» в настройках.

GitHub Actions проверяет и публикует сборку при обновлении ветки `main`. Текущий запуск можно открыть во вкладке Actions в репозитории.

## Локальный запуск

Нужен Node.js 22.12 или новее. В рабочей папке проекта выполни:

```powershell
npm ci
npm run dev
```

Открой [локальный PDD](http://127.0.0.1:5173/). Для автономного режима запусти собранную версию:

```powershell
npm run build
npm run preview
```

Открой [собранный PDD](http://127.0.0.1:4173/) с доступом к сети или к локальному серверу и дождись сообщения «Кэш готов» в настройках. После этого оболочка, справочник, перекрёстки и материалы из сборки доступны при отключённой сети. Сохраняй один и тот же адрес для продолжения обучения. У разных адресов и портов отдельные хранилища. Перенести историю можно через «Настройки → Резервная копия».

На Mac можно запустить те же команды локально.

В PowerShell с ограничением запуска сценариев используй `npm.cmd` вместо `npm`.

## Комплект ABM

В поставке **0 из 800 подтверждённых официальных позиций**. Ведомственная страница была недоступна, а разрешение на включение полного стороннего комплекта с рисунками не подтверждено. Два доступных билета содержат **40 авторских вопросов**, которые сверены с ПДД и явно обозначены как учебные. Они доступны и для учебного экзамена. Счётчик официального охвата учитывает только позиции ABM.

Подлинный разрешённый комплект можно проверить и подключить локально. Пример:

```powershell
npm run import:abm -- --input "C:/data/abm/pack.json" --answers "C:/data/abm/answers.json" --assets "C:/data/abm/images"
npm run validate:bank -- --answers "C:/data/abm/answers.json"
npm run build
```

[Формат файлов и условия проверки](docs/question-bank.md) · [Исследование экзамена и источники](docs/research.md)

## Учебные режимы

- В билетах клавиши 1–5 выбирают вариант, стрелки меняют вопрос. Во время экзамена выбор нужно подтвердить отдельной кнопкой. Иллюстрация открывается в окне с изменением масштаба.
- Вопрос без ошибок считается освоенным после двух верных ответов подряд. После ошибки нужны три. История неправильных ответов остаётся в журнале, а интервалы повторения растут с серией верных ответов.
- В перекрёстках можно выбрать участника на схеме или в списке. Для независимых траекторий тренажёр принимает разные очерёдности и совместный проезд. Задачи прошли сверку с ПДД и повторную редакционную проверку. [Правила и модель тренажёра](docs/intersections.md)
- Экспорт содержит ответы, результаты билетов и экзаменов, попытки на перекрёстках и закладки. При импорте журналы объединяются. Для незавершённого занятия используй исходный браузер.

## Проверки

```powershell
npm test
npm run validate:bank
npx playwright install chromium webkit
npm run test:e2e
npm run build
```

Playwright запускает сборку на порту 4173 и проверяет её в Chromium и мобильном WebKit с параметрами iPhone 13. Снимки экранов находятся в `test-results/`. Проверки структуры 800 позиций используют изолированные тестовые данные. Для проверки официальных вопросов нужен исходный комплект.
